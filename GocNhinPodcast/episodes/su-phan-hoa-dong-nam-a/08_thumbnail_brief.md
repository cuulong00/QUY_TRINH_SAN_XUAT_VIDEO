   ```bash
   # Sử dụng model: gemini-3.1-flash-image-preview (hoặc gemini-3-pro-image-preview)
   # Aspect Ratio: 16:9 native
   ```
2. **Lệnh Upscale 4K Chuẩn:**
   ```bash
   ffmpeg -i thumbnail_raw.png -vf "scale=4096:2304:flags=lanczos,unsharp=3:3:1.0:3:3:0.0" thumbnail_4k.png -y
   ```
3. **Kiểm tra độ nét trên Mobile:** Kiểm tra file hiển thị ở kích thước thumbnail thu nhỏ (120×68px) để bảo đảm 100% dòng chữ `ĐỔI NGÔI THẬT HAY GIẢ?` đọc được rõ ràng trong vòng 0.5 giây.
