# Antigravity Workspace Rules

## Mission
This repository is a content operating system for producing long-form Vietnamese YouTube scripts about finance, economics, investment, personal finance, and financial literacy.

## Required operating mode
Always work in: Plan -> Execute -> Verify.
Never jump directly from a raw topic to a full script.

## Source of truth
The repository files are the source of truth, not chat memory.
Always read and update files.

## Mandatory core files
Always consult:
- `00_core/channel_bible.md`
- `00_core/audience_personas.md`
- `00_core/financial_boundaries.md`
- `00_core/hook_library.md`
- `00_core/longform_blueprint.md`
- `00_core/voiceover_style_guide.md`
- `00_core/quality_rubric.md`
- `00_core/anti_patterns.md`

## Mandatory episode state
Every episode must maintain:
- `01_topic_qualification.md`
- `02_research_map.md`
- `03_brief.md`
- `04_hook_pack.md`
- `05_thesis_map.md`
- `06_retention_map.md`
- `07_outline.md`
- `08_chapter_briefs.md`
- `09_continuity_packet.md`
- `10_claim_ledger.md`
- `chapter_XX.md`
- `scene_timing_map.json`, `visual_storyboard_blueprint.md`, `prompts_chapter_XX.txt` (I2V Reference Asset Protocol — chỉ khi có yêu cầu)

## Never do these
- never fabricate financial data or statistics
- never give specific buy/sell investment advice
- never promise returns or guarantee getting rich
- never write a 40–60 minute script one-shot
- never skip continuity update after a chapter
- never use random visuals or surreal abstract elements in final mapping
- never create fake FOMO to manipulate viewers

## Quality constraints
- Start from financial pain or shocking data, not abstract theory
- Keep voice sharp, data-driven, and spoken
- Preserve one dominant analytical function per chapter
- Use financial caution and always include disclaimers
- Remove repetition aggressively
- Optimize for retention and oral delivery
- Every chapter must have at least 1 case study or concrete data point

## Deliverable discipline
When editing a file, return the full file.
When completing a phase, state what changed.
When uncertain, reduce claims and add disclaimers.

## Review discipline
Before marking a task done, verify:
1. continuity preserved
2. no financial overclaiming or buy/sell advice
3. tone matches channel bible (sharp, data-driven, actionable)
4. script is easy to voice
5. output file names are correct
6. disclaimer is present
7. Google Search AI Mode audit has been executed to verify the correctness of the latest 2025-2026 data and public policies (mandatory default check).
